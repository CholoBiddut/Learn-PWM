# ESP32-C3 PWM LED Brightness Controller

A simple and interactive ESP32-C3 project for controlling LED brightness using PWM (Pulse Width Modulation).

The project includes a real-time web dashboard where you can adjust the LED brightness smoothly using a slider.

## Features
- ESP32-C3 based
- PWM LED brightness control
- Real-time web dashboard
- Smooth brightness adjustment
- Responsive UI
- Wi-Fi Access Point mode
- No external potentiometer required

## Hardware
- ESP32-C3
- LED
- Current-limiting resistor
- USB cable / power source

- C/C++
- ESP32-C3
